To set the RUC of the electronic system provider according to SRI Resolution NAC-DGERCGC26-00000027
- Go to `Invoicing > Configuration > Settings`.
- In the `Ecuadorian Localization` section, set the `RUC Provider`.

The SRI authorization number returned by the web service is stored automatically on each authorized electronic document, next to the authorization date. No manual configuration is needed
- Go to `Invoicing > Configuration > Ecuadorian SRI > XML Electronic Documents`.
- Check the `Authorization Number(EC)` column of the list, or open a document to see it in the form.
